# 지갑 연결 추가 점검, 2026-11-10

지갑 선택과 연결 상태, 체인 전환, Pool·Liquid staking의 계정별 조회, 거래 시작 조건, 연결 해제, 모바일 메뉴를 점검했다. 기존 전체 테스트도 실행했다. 이번 기록은 애플리케이션 코드와 일부 로컬 화면에 대한 점검이며, 모든 지갑 확장 프로그램과 모바일 앱의 실제 연결을 검증했다는 뜻은 아니다.

## 수정한 문제

| 문제 | 원인과 수정 |
| --- | --- |
| 선택하지 않은 EVM 세션이 지갑 선택을 덮어씀 | Wagmi의 남은 연결을 보고 지갑 종류를 자동 변경하던 효과를 제거했다. 저장된 사용자 선택과 명시적 연결 성공을 기준으로 삼는다. |
| 이전 XPLA·Klip 주소가 다른 체인에 표시됨 | 공통 지갑 훅에서 현재 체인과 선택된 지갑 종류를 함께 검사한다. Overview에서도 선택하지 않은 XPLA 세션을 제외한다. |
| 연결 표시와 XPLA 거래 가능 여부가 다름 | 거래 훅이 제공자의 과거 세션을 직접 읽던 경로를 공통 지갑 훅으로 바꿨다. 선택하지 않은 세션은 거래 버튼을 활성화하거나 거래를 제출할 수 없다. |
| 잘못된 네트워크의 계정으로 메인넷 잔액·포지션을 조회함 | Aptos는 현재 chain ID, Sui·IOTA는 현재 계정의 메인넷 지원 여부를 검사한다. 공통 표시와 Pool·Liquid staking 조회에 적용했다. |
| 늦게 끝난 EVM 연결이 이전 체인으로 전환함 | 연결 시작 시 선택 체인을 기억하고 연결 응답, 네트워크 전환 전후, 활성화 시 다시 검사한다. 체인이 바뀌었으면 성공으로 처리하지 않는다. |
| BENQI 연결 취소 전에 지갑 종류가 이미 변경됨 | 별도 RainbowKit 연결 경로 대신 공통 지갑 선택 창에 Avalanche C-Chain ID를 전달한다. 연결과 네트워크 전환이 성공해야 활성화된다. |
| Sui 연결 해제 후 늦은 승인이 연결을 되살림 | 연결 요청 번호로 오래된 승인을 식별한다. 취소된 요청의 승인 세션은 해제하고 로컬 연결에 반영하지 않는다. |
| 이전 Sui 세션의 이벤트가 현재 연결을 지움 | 이벤트의 세션 ID가 현재 연결과 같을 때만 상태를 지운다. |
| Sui 원격 해제 실패 후 로컬 주소가 남음 | 원격 요청 전에 로컬 연결을 해제한다. 실패는 호출자에게 전달한다. |
| 지갑 해제·주소 복사 실패가 사용자에게 보이지 않음 | 비동기 해제 결과를 호출자에게 반환하고 지갑 버튼에서 실패를 표시한다. 주소 복사에는 성공·실패 알림을 추가했다. |
| 모바일에서 체인을 바꿔도 메뉴가 남음 | 사이드바 체인 선택 완료 후 모바일 메뉴의 닫기 콜백을 실행한다. |
| 미연결 사용자가 Stake 입력 창 안에서 진행할 수 없음 | 입력 창 안에 지갑 버튼을 추가했다. 거래 처리 중에는 지갑 변경 버튼을 표시하지 않는다. |

## 재현과 검증

수정 전에 실제 훅·컴포넌트 코드를 실행하는 테스트로 실패를 확인했다. 지갑 응답과 체인 조회는 테스트 대역을 사용했고, 늦은 승인은 수동으로 완료할 수 있는 Promise로 재현했다. 빈 계정, 다른 네트워크, 오래된 세션 이벤트, 연결 취소, 원격 해제 실패, 중복 클릭도 확인했다.

기존 테스트는 거래 데이터 생성과 서명 전 검증에 집중돼 있었다. 여러 세션이 함께 남는 상황, 사용자 선택과 제공자 연결의 불일치, 늦은 승인·해제 응답은 충분히 다루지 못했다. 이를 `wallet-state`, `wallet-network-queries`, `evm-connection-lifecycle`, `sui-wallet-session`, `cosmos-wallet-selection`, `wallet-button-actions` 테스트로 보완했다.

- `node --test scripts/*.test.mjs`: 297개 통과.
- `tsc --noEmit`: 통과.
- 전체 ESLint: 오류 없음. 기존 `scripts/wallet-view.test.mjs`의 미사용 `unoptimized` 경고 1개 유지.
- `git diff --check`: 통과.
- 로컬 Brave 브라우저: Sui 실제 검증인 목록, Stake 입력 창, 창 안의 Connect Wallet 버튼, Sui 지갑 선택 목록 확인. WalletConnect 설정이 없을 때 비활성화와 안내도 확인했다.

## 확인하지 못한 범위

`next build`는 Google Fonts의 Inter·Geist Mono 다운로드 실패로 완료하지 못했다. 네트워크 제한을 완화한 실행에서도 같은 오류가 발생했다. 개발 서버에서는 `/stake/sui`가 HTTP 200으로 응답하고 화면이 정상 렌더링됐다. 빌드 실패를 숨기기 위해 폰트나 프로젝트 설정을 바꾸지는 않았다.

브라우저에서는 지갑 선택 창을 확인한 뒤 제어 도구가 시간 초과됐다. 취소 후 폼 복귀와 모바일 실화면 검증은 완료하지 못했다. 실제 지갑 승인·서명·자금 이동은 수행하지 않았다. WalletConnect 프로젝트 설정이 없는 환경이므로 모바일 연결 완료까지 검증하지 않았다.

기존 점검 기록의 Liquid staking 포지션이 공통 Portfolio·Overview 합계에 통합되지 않은 제한은 여전히 남아 있다. 이번 수정은 지갑 상태와 조회 대상의 정확성을 다루며, 해당 데이터 통합을 완료한 것은 아니다. 커밋과 배포는 수행하지 않았다.
